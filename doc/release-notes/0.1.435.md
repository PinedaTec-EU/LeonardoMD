# LeonardoMD 0.1.435

## Open Leonardo documents and forms

- Author open MDLF documents with versioned metadata and Markdown content; ordinary Markdown files keep their standard behavior.
- Export MDLR forms with typed fields, validation and answers stored separately from the body. Save unfinished drafts.
- Configure backgrounds, image sizing/placement and table widths.
- Bundle documents and local assets as ordinary MDLZ ZIP packages. Edit the package directly or extract it to a folder, with a visible save destination.
- Preserve source files, local assets and external-change conflicts across saving and export.
- Generate and validate packages with the included Codex/Claude format plugin and Python helper.

Known format limitations: legacy ZIP filename encoding and padded closing delimiters are tracked separately in [#181](https://github.com/PinedaTec-EU/LeonardoMD/issues/181) and [#182](https://github.com/PinedaTec-EU/LeonardoMD/issues/182).

## Installation and updates

Beta for Apple Silicon (arm64), macOS 14 or later. Developer ID signed and notarized by Apple.

To receive beta updates, select **Beta** in Preferences → Updates. Stable remains the default subscription.

Update detection and installation are maintainer-confirmed. **Known limitation:** the active instance can remain open when updating from Preferences. Save your work, close Preferences, and quit normally to let the pending update complete. [Termination issue #202](https://github.com/PinedaTec-EU/LeonardoMD/issues/202).

Legacy betas using the former update-signing key require manual installation of a current signed/notarized package. This is separate from normal update installation and does not mean the current feed is unavailable.

[Publication evidence and validation limits](https://github.com/PinedaTec-EU/LeonardoMD/issues/223#issuecomment-6288007726). Notes clarified on 2026-10-20; original archive, version and channel are unchanged.
