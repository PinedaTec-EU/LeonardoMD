# LeonardoMD 0.1.405

## Home improvements and fixes

- Browse recent documents, projects and workspaces in separate Home tabs alongside persistent favorites.
- Home artwork adapts to smaller windows and appears behind the content.
- Avoid duplicate recent projects/workspaces when opening the same folder through different URL forms. Existing duplicates are cleaned while preserving order and favorites.

This stable release predates MDLF, MDLR, MDLZ and Leonardo forms. Choose a beta whose notes include Leonardo document support to try those workflows.

## Installation and updates

Stable for Apple Silicon (arm64), macOS 14 or later. Developer ID signed and notarized by Apple.

Update detection and installation are maintainer-confirmed. **Known limitation:** the active instance can remain open when updating from Preferences. Save your work, close Preferences, and quit normally to let the pending update complete. [Termination issue #202](https://github.com/PinedaTec-EU/LeonardoMD/issues/202).

Legacy betas using the former update-signing key require manual installation of a current signed/notarized package. This is separate from normal update installation and does not mean the current feed is unavailable.

[Publication evidence and validation limits](https://github.com/PinedaTec-EU/LeonardoMD/issues/223#issuecomment-6288007726). Notes clarified on 2026-10-20; original archive, version and channel are unchanged.
