# Bundled user guide

The macOS app ships `Guide-v3-en.mdlz` and `Guide-v3-es.mdlz` in its SwiftPM
resource bundle. Help and Welcome open a user-owned copy in
`~/Library/Application Support/LeonardoMD/User Guides/v3/<language>/` through
ordinary document tabs in package mode, without changing the user’s general
package-opening preference. Existing copies and practice answers are preserved.

`en/body.md` and `es/body.md` are the editorial sources. The package builder
owns the shared practice-field metadata and three SVG illustrations per locale plus the existing approved About banner as a local cover image.
Run `python3 scripts/package-user-guide.py` after changing either source;
the canonical plugin transport helper validates and deterministically packages
one `guide.mdlf` and local `assets/`. Regression tests compare generated bytes
to the committed artifacts, and native tests open them through LeonardoCore.
The regular app packaging copies the SwiftPM resource bundle unchanged.

For a later guide revision, advance the resource names and personal-copy revision
path together; never overwrite a user's saved copy to update the guide.
Keep locale content aligned and recheck vendor setup instructions and dates.
Do not claim agent control of the running app or unverified attachment gestures.

Tracking: [#290](https://github.com/PinedaTec-EU/LeonardoMD/issues/290).

Every language in `AppLanguage.allCases` must have a matching guide resource.
`BundledUserGuideTests` checks all supported languages; Help and Welcome resolve
the current `LanguageSettings.shared.language` on every opening. Native process
acceptance covers changing the preference between Spanish and English; see
[packaged guide acceptance](../validation/user-guide/README.md).

Revision 3 adds real Mermaid, KaTeX and Vega-Lite examples, literal source samples,
per-example extension requirements and consent/reset instructions in both languages.
The app opens a separate v3 copy; existing v2 copies and practice answers stay intact.
Native WebKit tests verify all four images and the three generated outputs.
