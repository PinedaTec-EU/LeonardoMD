# Bundled user guide

The macOS app ships `Guide-v2-en.mdlz` and `Guide-v2-es.mdlz` in its SwiftPM
resource bundle. Help and Welcome open a user-owned copy in
`~/Library/Application Support/LeonardoMD/User Guides/v2/<language>/` through
ordinary document tabs in package mode, without changing the user’s general
package-opening preference. Existing copies and practice answers are preserved.

`en/body.md` and `es/body.md` are the editorial sources. The package builder
owns the shared practice-field metadata and three SVG illustrations per locale.
Run `python3 scripts/package-user-guide.py` after changing either source;
the canonical plugin transport helper validates and deterministically packages
one `guide.mdlf` and local `assets/`. Regression tests compare generated bytes
to the committed artifacts, and native tests open them through LeonardoCore.
The regular app packaging copies the SwiftPM resource bundle unchanged.

For a later guide revision, advance the resource names and personal-copy revision
path together; never overwrite a user's saved copy to update the guide.
Keep locale content aligned and recheck vendor setup instructions and dates.
Do not claim agent control of the running app or unverified attachment gestures.
