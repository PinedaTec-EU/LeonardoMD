# Citation example

LeonardoMD can render an offline APA citation such as [@knuth1984]. A citation
source block stays in the Markdown document and is hidden only in the preview.

```bibtex
@book{knuth1984,
  author = {Knuth, Donald E.},
  title = {The TeXbook},
  year = {1984},
  publisher = {Addison-Wesley}
}
```
